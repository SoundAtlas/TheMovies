# The Movies

Semester project developed as part of the Datamatiker programme. The application is a cinema management system for managing movies, cinemas, screenings and bookings.

## Technologies

- C# and .NET 10
- WPF
- MVVM
- MSTest
- JSON file persistence

## Project structure

- `TheMovies.Core` - Domain models, services, repository interfaces and file-based repositories
- `TheMovies.WPF` - Windows desktop application built with WPF and MVVM
- `TheMovies.Tests` - Unit tests for the core logic and view models

## Running the application

1. Clone the repository.
2. Open `TheMovies.slnx` in Visual Studio.
3. Set `TheMovies.WPF` as the startup project.
4. Run the application.

The project requires Windows and the .NET 10 SDK.
